# StyleMix: сведение одной ручкой (VST3 для FL Studio)

Плагин на мастер или на шину микса. Выбираешь стиль, крутишь большую ручку **СВЕДЕНИЕ**, готово.

## Стили

| | BULLY | MILITANTUM |
|---|---|---|
| Характер | тёплый, грязный, винтажный соул-сэмпл звук | тёмный, злой, «боевой» |
| Низ | плотный бас (+3.5 dB на 90 Гц) | тяжёлый саб (+4.5 dB на 55 Гц) |
| Середина | тёплая (+1.5 dB на 280 Гц) | вычищена грязь (−3.5 dB на 420 Гц) |
| Верх | приглушён, как с плёнки (срез на 13.5 кГц) | атака и яркость (+2.5 dB на 2.6 кГц, полка +2 dB) |
| Компрессия | склейка 4:1, мягкая атака | жёсткая 6:1, быстрая атака |
| Сатурация | плёночная, с асимметрией | жёсткий клиппер |
| Стерео | чуть уже, «винтажно» | шире на 35 % |
| Пространство | короткая тёмная комната | большой ревер + пинг-понг дилей в темп проекта |

Это моя интерпретация звучания альбомов, а не копия чужого микса. Все цифры лежат в `Source/StylePresets.h`, их можно менять под себя.

## Ручки

- **СВЕДЕНИЕ** (Amount): 0 % ничего не меняет, 100 % даёт стиль целиком. Начни с 50–70 %.
- **ГРЯЗЬ** (Drive): сила сатурации, 0–200 %.
- **ПРОСТРАНСТВО** (Space): количество ревера и дилея, 0–200 %.
- **ГРОМКОСТЬ** (Output): от −12 до +12 dB. На выходе стоит лимитер с потолком −0.3 dBFS, поэтому трек не клипует.

Внизу полоска показывает, сколько dB давит компрессор.

## Сборка под Windows

### Вариант А: на своём компьютере (один раз ~40 минут на установку, потом ~5 минут сборка)

1. Поставь **Visual Studio Build Tools 2022**: https://visualstudio.microsoft.com/visual-cpp-build-tools/
   В установщике отметь **«Desktop development with C++»** («Разработка классических приложений на C++»).
2. Поставь **CMake**: https://cmake.org/download/ (Windows x64 Installer, при установке выбери «Add CMake to PATH»).
3. Поставь **Git**: https://git-scm.com/download/win (всё по умолчанию).
4. Перезагрузи компьютер.
5. Открой папку `StyleMix` и дважды кликни **`build_windows.bat`**. Первый раз он сам скачает JUCE, это займёт пару минут.
6. Готовый плагин появится тут: `build\StyleMix_artefacts\Release\VST3\StyleMix.vst3`

### Вариант Б: собрать на GitHub, ничего не устанавливая

1. Создай на GitHub пустой репозиторий и загрузи туда содержимое папки `StyleMix` (можно через кнопку «Upload files»; папку `.github` тоже нужно загрузить).
2. Открой вкладку **Actions**, там запустится «Build Windows VST3» (~10 минут).
3. Когда сборка позеленеет, внизу страницы в разделе **Artifacts** скачай `StyleMix-VST3-Windows` и распакуй.

## Установка в FL Studio

1. Скопируй папку `StyleMix.vst3` в `C:\Program Files\Common Files\VST3\`
2. В FL Studio: **Options → Manage plugins → Find installed plugins**.
3. Добавь **StyleMix** в слот на мастер-канале микшера (или на шину, куда идёт весь бит и вокал).

## Что можно добавить дальше

- Режим «Вокал» (отдельные пресеты для голоса: де-эссер, яркость, дилей на хвостах).
- Больше стилей.
- Плавный переход при переключении стилей прямо во время воспроизведения (сейчас возможен короткий щелчок).
