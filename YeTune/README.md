# YeTune — автотюн для вокала (в стиле Kanye West)

VST3-плагин для FL Studio. Кидаешь на дорожку с голосом, выбираешь тональность бита — голос притягивается к нотам лада.

## Как это звучит без «бурундука» и «демона»

Сдвиг высоты сделан методом PSOLA: голос режется на кусочки длиной в два периода основного тона и складывается обратно с новым шагом. Форманты (тембр, «размер» рта) остаются на месте, меняется только высота нот. Поэтому голос не становится мультяшным при подтяжке вверх и не становится «демоническим» при подтяжке вниз.

## Ручки

| Ручка | Что делает |
|---|---|
| ТОНАЛЬНОСТЬ / ЛАД | Тональность бита. Если не знаешь — «Хроматический», тогда голос тянется к ближайшей любой ноте. |
| СКОРОСТЬ | 0 мс = мгновенно, жёсткий роботский эффект (Kanye, *808s & Heartbreak*, T-Pain). 30–80 мс = просто ровный вокал, 150+ мс = еле заметно. |
| ЖИВОСТЬ | Смягчает самое начало каждой ноты, середина ноты остаётся ровной. |
| СИЛА | Насколько сильно тянуть к ноте (100% = до конца). |
| МИКС | Смесь с исходным голосом. |
| ГРОМКОСТЬ | Выходной уровень. |

Кнопки сверху: **ЖЁСТКО (как у Kanye)** и **ЕСТЕСТВЕННО** — быстрые пресеты.

Совет: для эффекта Kanye держи СКОРОСТЬ на 0 и ставь правильную тональность — тогда слышны «ступеньки» между нотами.

Плагин добавляет задержку ~46 мс, FL Studio компенсирует её автоматически.

## Сборка

GitHub Actions собирает VST3 под Windows при каждом пуше в `YeTune/` (workflow «Build YeTune (Windows VST3)», артефакт `YeTune-VST3-Windows`). Скачай архив, распакуй папку `YeTune.vst3` в `C:\Program Files\Common Files\VST3`, в FL Studio: Options > Manage plugins > Find more plugins.

Локально: `cmake -S YeTune -B build && cmake --build build --config Release --target YeTune_VST3`.
