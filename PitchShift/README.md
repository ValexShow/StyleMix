# VoxShift — питч-шифтер для вокала без «демона» и «бурундука»

VST3-плагин для FL Studio: поднимает и опускает голос на октавы и полутоны,
но оставляет форманты (тембр, «размер горла») на месте. Поэтому вниз голос
не превращается в демона, а вверх — в бурундука.

## Ручки

| Ручка | Что делает |
|---|---|
| **ОКТАВА** (кнопки −2…+2) | Сдвиг на целые октавы |
| **ПОЛУТОНЫ** | −12…+12 полутонов (складывается с октавой) |
| **ТОЧНО** | Подстройка ±100 центов |
| **ТЕМБР** | Отдельный сдвиг формант ±12. Минус — голос толще/ниже по тембру, плюс — тоньше. 0 = как в оригинале |
| **ЕСТЕСТВЕННОСТЬ** | 100% = форманты стоят на месте (естественно). 0% = классический сдвиг (демон/бурундук) |
| **МИКС** | Сухой/обработанный. 100% = только сдвинутый голос, 50% = дабл/гармония с оригиналом |
| **ГРОМКОСТЬ** | Выходной уровень ±12 dB |

Громкость после сдвига автоматически выравнивается по оригиналу.
Задержка (~40 мс) сообщается FL Studio, и он её компенсирует сам.

## Как это работает

Фазовый вокодер с «привязкой фаз» к гармоникам (каждая гармоника голоса
переносится целиком, без металлического призвука) плюс оценка спектральной
огибающей через кепстр: после сдвига громкость гармоник подгоняется так,
чтобы огибающая (форманты) осталась как у оригинала. При понижении верхний
«воздух» (шипящие, дыхание) берётся из оригинала, чтобы голос не становился
глухим. Код DSP — `Source/FormantPitchShifter.h`.

Лучше всего работает на одном голосе (сольный вокал, бэки, речь).

## Сборка

Собирается автоматически через GitHub Actions (workflow «Build VoxShift»):
Actions → последний запуск → артефакт `VoxShift-VST3-Windows`. Внутри папка
`VoxShift.vst3` — скопируйте её в `C:\Program Files\Common Files\VST3`,
затем в FL Studio: Options → Manage plugins → Find installed plugins.

Локально (нужны Visual Studio Build Tools и CMake):

```
cmake -S PitchShift -B build -A x64
cmake --build build --config Release --target VoxShift_VST3
```
