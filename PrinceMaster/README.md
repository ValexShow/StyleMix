# PrinceMaster — мастер-плагин в духе Тёмного Принца

VST3 для FL Studio, который кидается **последним на мастер** (Master в микшере).
Два режима по мотивам треков «Завтра» и «One More Time». Это не копия чужого мастера,
а интерпретация характера: фонящий размашистый хип-хоп, где всё искажено, шипит и качается,
плюс цифровая грязь в духе дигикора.

## Режимы

- **ЗАВТРА** — толстый низ, гнусавая «фонящая» середина, пережатый фузз, шипение и гул,
  огромный тёмный зал, широкое стерео, лёгкое качение.
- **ONE MORE TIME** — сильное качение от бочки (как сайдчейн), жёсткий цифровой клиппер,
  битовая грязь, яркий верх, зал поменьше.

## Ручки

| Ручка | Что делает |
|---|---|
| **СИЛА** | Главная ручка. 0 % = сигнал проходит как есть, 100 % = полный стиль. Начни с 60–80 %. |
| **ИСКАЖЕНИЕ** | Сколько фузза/клиппера (100 % = как задумано в режиме, до 200 %). Громкость от неё не прыгает — есть автокомпенсация. |
| **ФОН** | Шипение плёнки, гул 50 Гц и треск. Дышит вместе с треком и почти пропадает в тишине. |
| **ЦИФРА** | Понижение разрядности и частоты — «битая» цифровая грязь. |
| **КАЧ** | Насколько бочка «толкает» вниз всё остальное. Сама бочка почти не проседает. |
| **ПРОСТРАНСТВО** | Зал и ширина стерео. В зал уходит только середина, низ остаётся сухим. |
| **ГРОМКОСТЬ** | Выход ±12 dB. Дальше стоит мягкий клиппер и лимитер с потолком −0.3 dBFS, так что в красное не уйдёт. |

Внизу два индикатора: насколько сейчас качает (**Качение**) и насколько работает лимитер (**Лимитер**).
Если лимитер постоянно давит больше 3–4 dB — убавь ГРОМКОСТЬ.

## Цепочка

EQ → качение от бочки → искажение (2x передискретизация) → цифра → склейка компрессором →
фон → ширина → зал на посыле → громкость → мягкий клиппер → лимитер −0.3 dBFS.

## Как получить плагин

Сборку делает GitHub Actions (Build Tools ставить не нужно):

1. Открой вкладку **Actions** в репозитории → **Build PrinceMaster VST3** → последний зелёный запуск.
2. Внизу в **Artifacts** скачай `PrinceMaster-VST3-Windows` и распакуй.
3. Папку `PrinceMaster.vst3` скопируй в `C:\Program Files\Common Files\VST3`.
4. В FL Studio: **Options → Manage plugins → Find installed plugins**, затем вставь PrinceMaster на слот мастера.

Собрать у себя можно через `build_windows.bat` (нужны Visual Studio Build Tools, CMake и Git).
