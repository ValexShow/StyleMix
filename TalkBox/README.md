# TalkBox: голос как у Daft Punk без железного толкбокса (VST3 для FL Studio)

Вешаешь на трек с записанным голосом, и голос начинает «петь синтезатором», как в «Around the World» или у Zapp & Roger.

Как это работает: в настоящем толкбоксе синт играет в трубку во рту, а рот делает из звука слова. Плагин делает то же самое в цифре: каждые 2.5 мс он считывает из голоса форму рта (гласные, согласные) и накладывает её на встроенный синтезатор.

## Три режима

| Режим | Откуда берутся ноты | Когда брать |
|---|---|---|
| **АВТО (по голосу)** | плагин сам слышит, какую ноту ты поёшь, и подтягивает её к ладу | быстрый старт, ничего не надо настраивать |
| **MIDI (ноты)** | из Piano roll, можно аккордами | когда хочешь сыграть точную мелодию или аккорды поверх речи |
| **САЙДЧЕЙН (свой синт)** | любой твой синт (Sytrus, Serum, 3x Osc…) | когда нужен свой тембр синта |

### Настройка MIDI в FL Studio
1. Открой плагин, нажми шестерёнку в его окне (Plugin options), справа внизу **MIDI → Input port**: поставь, например, **1**.
2. Добавь в Channel rack канал **MIDI Out** (Add → MIDI Out), в нём поставь **Port** тот же **1**.
3. Пиши ноты в Piano roll этого MIDI Out. Голос можно просто говорить, плагин споёт его твоими нотами.

### Настройка сайдчейна в FL Studio
1. Синт выведи на свой трек микшера и сними у него отправку в мастер (если не хочешь слышать его отдельно).
2. Выдели трек синта, на треке с голосом ПКМ по стрелке внизу → **Sidechain to this track**.
3. В плагине выбери **САЙДЧЕЙН**. В окне FL у плагина (шестерёнка → Processing) проверь, что вход сайдчейна назначен на этот трек.

## Ручки

- **ТОНАЛЬНОСТЬ / ЛАД** (Авто): к каким нотам притягивать голос. По умолчанию A минор.
- **ОКТАВА** (Авто): сдвиг синта на ±2 октавы.
- **РОБОТНОСТЬ** (Авто): 100 % = ноты чётко по ступенькам (робот), 0 % = синт повторяет голос как есть.
- **ГЛАЙД**: как быстро синт съезжает между нотами. Мало = роботно, много = «плавающий» толкбокс.
- **ВОЛНА**: пила (ярко, классика) → квадрат (полый, «гнусавый»).
- **РАССТРОЙКА**: толщина синта (две пилы чуть врозь).
- **СОГЛАСНЫЕ**: добавляет шипение на «с», «ш», «т», чтобы слова были разборчивее.
- **ЯРКОСТЬ**: темнее ↔ ярче.
- **ГЕЙТ**: ниже этого уровня голос считается тишиной, синт замолкает (убирает гул в паузах).
- **МИКС**: 100 % = только толкбокс, меньше = подмешивается обычный голос.
- **ГРОМКОСТЬ**: выход ±.

**Аккорды (поли)**: в MIDI-режиме играть до 8 нот сразу. Выключи, если хочешь моно-партию с глайдом.

## Советы для звука Daft Punk
- Пиши голос чисто, без ревера; говори/пой чётко и немного утрированно открывай рот на гласных.
- Режим АВТО: Роботность 100 %, Глайд 20–40 мс, Волна 20–30 %.
- После плагина хорошо встают хорус, компрессор и немного ревера.

## Сборка
Собирается автоматически на GitHub (вкладка **Actions** → «Build TalkBox (Windows VST3)» → внизу архив **TalkBox-VST3-Windows**). Папку `TalkBox.vst3` из архива положи в `C:\Program Files\Common Files\VST3\` и в FL Studio сделай **Options → Manage plugins → Find plugins**.
